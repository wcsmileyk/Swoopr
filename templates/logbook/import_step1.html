How it works

  1. Upload your CSV export — we auto-detect the column layout.
  2. Confirm which columns map to which logbook fields (date, DZ, canopy, etc.).
  3. We fuzzy-match your dropzone and aircraft names against existing records so you don't end up with duplicates like "Z-Hills" and "Skydive City" both created.
  4. Set your starting jump number, then confirm the import.

Recognized columns

Date — jump date

Dropzone / DZ — location

Aircraft / Plane — jump plane

Canopy / Main — parachute

Type / Discipline — jump type

Altitude / Alt — exit altitude (ft)

Swoop — yes/no/x

Rotation / Degrees — turn °

Formation Size / FS

Notes / Comments

Starting jump number
